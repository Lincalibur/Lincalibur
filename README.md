### About

I'm a software developer based in the Western Cape, South Africa, focused on the intersection of security tooling and infrastructure automation. My guiding principle comes from Salvador Dalí: *"Intelligence without ambition is a bird without wings."*

- **Current focus:** Building **OpenClaw-Assistant**, a cybersecurity-focused AI assistant
- **Homelab:** Running a self-hosted **Docker** and **Rancher** cluster
- **Learning:** Signal intelligence techniques and bio-medical API integration
- **Open to:** Collaboration on open-source security tools and DevOps automation
